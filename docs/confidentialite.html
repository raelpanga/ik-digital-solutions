Informations sur le fonctionnement de ce portfolio · mise à jour le 16 septembre 2026.

Navigation sur le portfolio

Le code du portfolio ne met en place ni compte visiteur, ni traceur publicitaire, ni mesure d'audience. Les pages et leurs ressources sont demandées à l'hébergeur ; ces requêtes peuvent faire l'objet de journaux techniques gérés par les prestataires.

Polices et ressources

Les polices du site sont chargées depuis Google Fonts. Votre navigateur contacte ce prestataire lors du chargement. Les autres images du portfolio sont servies avec les pages.

Formulaire de contact

Les champs du formulaire sont transmis à Web3Forms (web3forms.com), un service d'acheminement de formulaires, qui nous les remet par e-mail à consultation@iksolutions-inc.com. Le portfolio ne conserve pas ces champs sur ses pages ni dans le stockage du navigateur. Le bouton WhatsApp prépare un message dans votre application, que vous confirmez vous-même.

Après votre message

Lorsque vous envoyez un message, les informations reçues servent à répondre à votre demande et à échanger sur votre projet. Pour une question relative à ces échanges ou une demande de suppression, écrivez à consultation@iksolutions-inc.com.

Démonstrateurs

Certains démonstrateurs utilisent le stockage local du navigateur pour conserver des scénarios, préférences ou opérations simulées. Utilisez des données fictives. Vous pouvez effacer ces données dans les réglages de votre navigateur ; une réinitialisation est aussi proposée dans certains exemples.

Services externes

Web3Forms, WhatsApp, votre messagerie, Google Fonts, GitHub Pages et les sites de production externes appliquent leurs propres pratiques de traitement des données. Cette page décrit le fonctionnement du portfolio, pas celui de ces services.
