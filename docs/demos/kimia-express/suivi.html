Questions sur le suivi

  • Je n'ai pas reçu de numéro de suivi.

    Il est envoyé par SMS dès la confirmation et visible dans l'application. Vérifiez le numéro de téléphone saisi, ou écrivez-nous sur WhatsApp avec le nom de l'expéditeur.

  • Pourquoi mon colis intervilles n'avance pas ?

    Les colis par avion attendent le prochain vol cargo disponible. Un vol reporté décale la livraison d'un jour ; vous recevez un SMS dès le nouveau départ.

  • Puis-je changer l'adresse de livraison ?

    Oui, tant que le colis n'est pas en cours de livraison, depuis la page de suivi ou par WhatsApp. En ville, un changement de zone peut ajouter 3 000 FC.
